# 0.2.0 — тестовая Windows-сборка

## Изменения

- Нейтральные подписи ARW в интерфейсе и документации.
- Выбор Русский / English с сохранением языка; переводятся также предупреждения,
  статусы, итог конвертации и диалоги. Пути, очередь и настройки сохраняются.
- Калибровка максимальной скорости оценивает медианную скорость отдельных
  фотографий при заполненной очереди, учитывая их разрешение. Учитываются только
  задачи, проведшие не менее 80% времени при целевом количестве активных задач.
  Время разгона между уровнями больше не занижает оценку уровня. Для решения нужны
  до четырёх завершённых задач; рост требует улучшения не менее 5%. CPU и RAM
  по-прежнему ограничивают запуск; приоритет не превышает обычный.
- Отчёт схемы 2: width/height — реальные размеры готового PNG после уменьшения
  и поворота; input_width/input_height — размеры из метаданных RAW до поворота.
  Если готового PNG нет, его размеры равны нулю. В queue добавлены история
  калибровки, её завершённость, выбранная параллельность, приоритеты и потоки.
- Версия приложения в отчёте — 0.2.0. В тестовом профиле диагностика включена.

## Проверки

72 теста прошли на Linux с настоящим ARW и 72 — на Windows Python 3.12.7
через Wine 9.17. Включены проверки языков, отмены, памяти, публикации файлов,
ошибок рабочих процессов и реальных размеров PNG. Регрессия калибровки проверяет
переходы 1 → 2 → 4 → 8 → 12, возврат к более быстрому уровню, исключение
незаполненной очереди, нормализацию разрешения и устойчивость к одному медленному
файлу. Сравнение фактической скорости на компьютере пользователя ещё требуется.

Сборочный образ тот же, что в 0.1.0:
`tobix/pywine@sha256:65dd1d8c0f3b4b951e49e9caababf12f497b02c45a883bd18c731e8eb9c2f9c0`.
Для проверки Wine использует native UCRT / OpenMP; эти настройки сборочной среды
пользователю Windows не требуются. Системная CA передаётся read-only и не входит
в пакет; TLS-проверка сохранена.

## Следующий прогон на Windows

Распаковать новый ZIP целиком в отдельную папку. Запустить ARW-to-PNG.exe,
проверить Русский / English на нескольких фотографиях. Затем обработать те же
68 ARW в PNG 16 бит, в режиме «Максимальная скорость», в новую пустую папку.
Сохранить JSON: app_version должен быть 0.2.0, schema_version — 2.
Сравнить с двумя прогонами 0.1.0: 204.891 и 203.641 с. Новая оценка параллелизма
не гарантирует ускорение на каждом компьютере, поэтому вывод делать по отчёту.

Готовый Windows EXE проверен на реальном ARW с кириллицей и пробелами в путях:
английский / PNG 16 бит — 4024×6024; русский / PNG 8 бит — 4024×6024;
английский / PNG 8 бит, половинный размер — 2012×3012. Все строки PNG полностью
декодированы, подтверждены глубина цвета, содержимое пикселей, один внутренний
поток, размеры в JSON и нормальное завершение каждого процесса. Служебная
автопроверка закрывает Qt-цикл в GUI-потоке без повторного app.quit() после
закрытия последнего окна.

Это тестовый портативный пакет без цифровой подписи. Python пользователю не нужен.
