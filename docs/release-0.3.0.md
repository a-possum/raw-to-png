# 0.3.0 — PNG 8 бит по умолчанию и тёмная тема

- Первый запуск: PNG 8 бит, полный размер, без автоосветления. Конвертер при
  вызове без указания глубины цвета также создаёт PNG 8 бит. PNG 16 бит доступен
  в пресете для обработки и дополнительных настройках.
- «Автоматически осветлять» видно в основном окне. Эта настройка независима
  от глубины цвета и пресета; включается вручную и не изменяется при смене
  пресетов. Начальное значение выключено во всех готовых вариантах.
- Старые стандартные настройки переводятся на новый начальный 8-битный профиль
  однократно. У быстрого пресета сохраняется уменьшение размера, а прежнее
  принудительное осветление отключается. Своим настройкам доверяем: они
  сохраняются. Последующий выбор 16 бит и ручного осветления запоминается.
- По умолчанию тёмная тема; светлая доступна вверху окна. Выбор темы и языка
  сохраняется. Темы меняют только оформление интерфейса, без изменения параметров
  конвертации или данных изображения. Цвета заданы также для таблицы, выделения,
  списков, предупреждения максимальной скорости и недоступных кнопок.
- Обновлены русские и английские подписи. В отчёте версия 0.3.0, схема 2.

## Проверка на Windows

Распаковать новый ZIP целиком в отдельную папку и открыть ARW-to-PNG.exe.
После первого обновления проверить PNG 8 бит без осветления и тёмную тему.
Поменять тему и язык; убедиться, что очередь и параметры конвертации сохраняются.
Перезапустить приложение и проверить сохранённый выбор темы и языка.

На одной фотографии выполнить полноразмерную конвертацию 8 и 16 бит, меняя только
глубину цвета и оставляя осветление выключенным, WB камеры и яркость 0 EV.
Ожидается близкая визуальная яркость. Затем включить осветление вручную и
проверить, что оно действует в обоих вариантах и не сбрасывается сменой пресета.

Калибровка максимальной скорости из 0.2.0 сохранена. Для сравнения скорости
использовать те же 68 ARW и PNG 16 бит, максимальный режим и новую пустую папку.
Не сравнивать напрямую время полного PNG16 и половинного PNG8: у них различаются
разрешение и объём данных. Сохранить JSON-отчёт для анализа.

Это тестовый портативный пакет без цифровой подписи. Python пользователю не нужен.

## Проверки сборки

81 тест прошёл на Linux с настоящим ARW. На Windows Python 3.12.7 / Wine 9.17
сначала прошёл полный набор из 80 тестов, затем после финальной правки интерфейса
повторно прошли все 27 проверок UI, включая новую проверку видимости предупреждения
в небольшом окне. Всего 81 уникальная проверка Windows. Регрессии проверяют
перенос старых пресетов, независимость осветления, сохранение 16 бит, обе темы,
оба языка, очередь и выделение строк после смены оформления.

Готовый EXE проверен на настоящем ARW: русский / тёмная тема / полный PNG8,
английский / светлая тема / полный PNG16, английский / тёмная тема / половинный
PNG8. Декодированы все строки PNG, проверены пиксели, глубина цвета, размеры в
отчёте, отсутствие автоосветления и нормальное завершение каждого процесса.
Первый запуск зафиксировал 8 бит, тёмную тему и выключенное осветление.

Сборочный образ закреплён тем же digest, что в 0.2.0. Для экономии места только
в одноразовом сборочном контейнере удалены неиспользуемые компоненты QtWebEngine;
приложение использует Qt Widgets. Зависимости установлены с проверкой TLS,
системный CA не включён в пакет. Лицензионные уведомления зависимостей сохранены.
