# 0.4.0 — иконка, оставшееся время и открытие PNG

- Оригинальная иконка: фотокадр с синей стрелкой. Один ICO используется в EXE,
  окне, диалогах и панели задач; для Windows задан постоянный AppUserModelID.
  ICO содержит PNG-кадры 16, 24, 32, 48, 64, 128 и 256 px. Исходник PNG и скрипт
  кодирования ICO включены в исходники; рисунок создан специально для проекта.
- Приблизительное оставшееся время после первых двух успешных конвертаций.
  Используются последние восемь работ, их время и разрешение, уже выполненная
  часть активных задач и текущая параллельность. Учитываются ограничение при
  снижении числа задач и последовательная подготовка новых процессов. Пропуски
  и ошибки не считаются скоростью успешной конвертации. При ожидании RAM или
  необычно медленной текущей задаче точное число скрывается и оценка уточняется.
- Двойной щелчок по готовой строке открывает её PNG стандартным просмотрщиком.
  Сохраняется настоящий путь результата; строки с ошибками, пропусками или
  незавершённой обработкой не открываются. Для удалённого файла и отказа
  системного просмотра есть понятное сообщение.
- Новые подписи переведены на русский и английский. При смене языка, отмене и
  повторном запуске не остаётся устаревшего обратного отсчёта.
- Версия в отчёте — 0.4.0, схема 2. PNG 8 бит, ручное осветление и тёмная тема
  по умолчанию из 0.3.0 сохранены.

## Проверка на Windows

Распаковать ZIP целиком в новую папку и открыть ARW-to-PNG.exe. Проверить иконку
в Проводнике, заголовке и панели задач. Добавить несколько снимков; после первых
успешных конвертаций проверить строку оставшегося времени. Дважды щёлкнуть по
готовой строке во время очереди и после завершения: должен открыться правильный
PNG. Повторить с кириллицей / пробелами в пути. После отмены, завершения и
повторного старта старая оценка времени должна исчезнуть. Темы и язык сохраняются.

Оценка приблизительная, особенно при смене числа обработчиков, смешанных камерах
и изменении нагрузки компьютера. Первое сравнение на реальном Windows требуется.
Это портативная тестовая сборка без цифровой подписи; Python пользователю не нужен.

## Автоматическая проверка

98 тестов прошли на Linux с настоящим ARW и 98 — на Windows Python / Wine.
Проверены новые сигналы оценки времени в настоящем QThread, отмена / завершение,
ожидание RAM, смена параллельности, разные разрешения, исключение пропущенных
файлов, локализация, открытие правильного file URL и отсутствие запуска строк
с ошибками. В ICO проверены все семь размеров и загрузка малых / больших кадров.

Сборочный образ закреплён тем же digest, что в 0.3.0. Из одноразового контейнера
удалены неиспользуемые Qt SDK / WebEngine и документация; все Qt-библиотеки
предыдущей проверенной сборки сохранены. TLS-проверка сохранена. Отдельно
проверяется, что PE содержит семь ресурсов иконки и группу иконок. Исходники
прошлых сборок, исходные фотографии и оригинал рисунка иконки сохранены.

Готовый EXE проверен с кириллицей в путях: русский / тёмная тема / полный PNG8,
английский / светлая тема / половинный PNG16, английский / тёмная тема /
половинный PNG8. Полностью декодированы строки PNG, проверены пиксели, размеры,
загрузка иконки и нормальный выход. Открытие результата проверено перехватом
QDesktopServices: передаётся именно созданный PNG; реальный просмотрщик должен
проверить пользователь на Windows. В PE подтверждены 7 RT_ICON и 1 RT_GROUP_ICON.
