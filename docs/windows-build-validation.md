# Проверка Windows-сборки 0.1.0 test

Получен Windows x64 exe, упакованный в ZIP с папкой `_internal` и диагностикой,
включённой по умолчанию. Python пользователю не требуется.

Сборка выполнена Windows Python 3.12.7 / PyInstaller 6.16.0 в изолированном Wine
9.17. Образ закреплён по digest:
`tobix/pywine@sha256:65dd1d8c0f3b4b951e49e9caababf12f497b02c45a883bd18c731e8eb9c2f9c0`.
TLS-проверка при установке зависимостей сохранена; CA передавался отдельным
read-only mount и не попал в пакет. Docker-образ и контейнер после сборки удалены.

Для проверки в Wine понадобилась оригинальная Microsoft UCRT. Использован
пакет conda-forge `ucrt-10.0.26100.0-h57928b3_0.conda`, SHA256
`3005729dce6f3d3f5ec91dfc49fc75a0095f9cd23bab49efb899657297ac91a5`,
проверенный по HTTPS repodata. В Wine применялся override
`WINEDLLOVERRIDES=ucrtbase,vcomp140=n,b`, чтобы Wine не подменял MS OpenMP.
Это настройка только сборочного окружения; на обычном Windows ничего настраивать
не нужно. В пакет не включены Wine builtin DLL. Исходные фото и тестовые
результаты в ZIP не включены.

Проверки:

- 54 теста прошли на Windows Python/Wine, два теста с реальным RAW отдельно прошли
  после подключения образца; дополнительный тест cgroup прошёл отдельно. Итого
  57 уникальных проверок. На Linux целевые проверки также пройдены.
- Готовый exe самостоятельно запустил рабочий процесс и преобразовал настоящий
  ARW в PNG RGB 16 бит, 4024×6024.
- Входной файл и выходная папка содержали кириллицу и пробелы.
- Полностью декодированы все строки PNG; проверено содержание пикселей, а не
  только заголовок. Ненулевых значений — более 99%, максимум — 65535.
- Подтверждены один внутренний поток и BELOW_NORMAL_PRIORITY_CLASS рабочих процессов.
- Сохранён диагностический JSON из готового exe; тестовый профиль включён в пакет.
- ZIP проверен на CRC; проверена архитектура PE AMD64, наличие qwindows.dll,
  отсутствие RAW-фотографий, CA сборщика и подменных Wine DLL.

Обнаруженные ошибки исправлены: `poll()` Windows pipe может выбрасывать
BrokenPipeError; высота предупреждения должна учитывать системные шрифты;
Linux cgroup должен учитывать освобождаемый файловый кэш при оценке RAM.

Сборка не подписана. Проверка на настоящем пользовательском Windows и большая
очередь из 68 файлов остаются следующим этапом; Wine не заменяет этот тест.
Внешние сценарии и логи сохранены в `/workspace/artifacts/windows-wine/`.

Разработчик может выполнить контроль готовой тестовой сборки:
`ARW-to-PNG.exe --packaging-check INPUT.ARW NEW_OUTPUT_DIRECTORY`.
Нужен заведомо нормальный освещённый кадр; проверка специально отбрасывает почти
чёрный результат. Команда доступна только тестовому профилю и не используется
в обычном интерфейсе. Выходная папка должна ещё не существовать.
