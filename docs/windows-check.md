# Первая проверка приложения на Windows

## Что записать один раз

В тестовой сборке диагностика включена автоматически. После каждого прогона
нажмите **«Сохранить отчёт»** и сохраните JSON с понятным названием режима.
Обычно достаточно прислать эти отчёты: время, CPU, RAM, ошибки и настройки
записываются автоматически. Ручные замеры ниже пригодятся для сравнения
с Диспетчером задач или при проблеме с диагностикой.

- Версия Windows (10/11).
- Модель процессора.
- Объём оперативной памяти.
- Диск для исходников и PNG: SSD или HDD.
- Для ноутбука — подключён ли он к питанию.

Эти сведения видны в «Параметры → Система → О системе» и «Диспетчер задач → Производительность».

## Первый запуск

Распакуйте ZIP со сборкой целиком. Запускайте ARW-to-PNG.exe из папки ARW-to-PNG.
Не переносите exe отдельно от остальных файлов. Исходный ZIP проекта не является сборкой.

В 0.3.0 первый запуск использует PNG 8 бит, полный размер, без автоосветления
и тёмную тему. Осветление видно в основном окне и включается вручную.
Проверьте выбор тёмной / светлой темы и сохранение выбора после перезапуска.

В следующей сборке проверьте переключатель **Русский / English** вверху окна:
названия кнопок, настройки, предупреждение максимальной скорости, очередь и
итоговый статус должны переводиться. Добавленные фотографии, пути и настройки
должны сохраняться. Закройте приложение и откройте снова: выбранный язык должен
восстановиться. Во время поиска файлов и обработки переключатель заблокирован.
Сборка 0.1.0 этого переключателя ещё не содержит.

Сначала используйте 5–10 ARW. Проверьте добавление папки, выбор папки сохранения,
PNG 8/16 бит и правильную ориентацию фотографий. Затем проверьте очередь из 100
или более ваших снимков. Учитывайте свободное место: 100 фотографий 24 Мп в PNG
16 бит могут занимать около 13 ГБ.

## Три сравнительных прогона

Используйте одни и те же 5–10 ARW, пресет «Для обработки · PNG 16 бит» и один диск.
Последовательно выполните «Экономный», «Авто» и «Максимальная скорость».
Для каждого запуска выбирайте отдельную пустую папку сохранения, чтобы приложение
не пропускало готовые PNG. Не запускайте режимы одновременно.

В максимальном режиме не используйте другие тяжёлые приложения. Для честного
сравнения остальных режимов также оставьте компьютер без других тяжёлых задач.

Запишите для каждого прогона:

| Режим | Файлов | Время из приложения | RAM группы приложения, наибольшее замеченное значение | CPU группы приложения, обычный диапазон | Ошибки | Окно отвечает? |
| --- | --- | --- | --- | --- | --- | --- |
| Экономный | | | | | | |
| Авто | | | | | | |
| Максимальная скорость | | | | | | |

CPU и память смотрите в «Диспетчер задач → Процессы». У приложения есть дочерние
процессы, поэтому учитывайте всю группу. Если группировка неочевидна, пришлите
скриншот строк приложения во время обработки. Ручные наблюдения дают приближённый
пик RAM — точность до мегабайта не требуется. Приоритеты вручную не меняйте.

Откройте и переместите окно, попробуйте открыть Проводник. Отметьте, есть ли
заметные зависания. После завершения пришлите скриншот итогового статуса.

## Проверка большой очереди

На 100+ фотографиях выберите предпочтительный режим. Посмотрите, не растёт ли
память непрерывно по мере завершения файлов и не становится ли компьютер менее
отзывчивым со временем. Отметьте снижение скорости, сильный шум вентиляторов
или заметное замедление ноутбука в конце очереди. Температуру и дополнительные
программы мониторинга устанавливать не обязательно.

## Проверка отмены и ошибок

- Остановите очередь посередине и дождитесь остановки. Завершённые PNG должны остаться.
- Убедитесь, что в выбранной папке нет незавершённых PNG или временных каталогов .arw-to-png-….
- Повторите запуск: готовые файлы должны получать новые имена либо пропускаться,
  в зависимости от выбранной настройки. Оригиналы ARW должны сохраняться.
- Проверьте исходники и папку сохранения с кириллицей и пробелами в пути.
- Не нужно специально заполнять диск или повреждать оригинальные фотографии.

## Что прислать

Достаточно характеристик компьютера, заполненной таблицы и скриншотов приложения
и Диспетчера задач. При ошибке — её полный текст, режим и имя файла, на котором она возникла.
Примерные секунды и мегабайты подходят, специальные технические инструменты не нужны.
