# Проверка пользователем на Windows, 31 октября 2026

Проверена портативная тестовая сборка 0.1.0. На компьютере Windows 10
(10.0.19045), CPU 6 физических ядер / 12 логических потоков, около 32 ГиБ RAM.
Пользователь подтвердил, что готовые PNG открываются и выглядят нормально,
а отмена посередине очереди и повторный запуск работают корректно.

В трёх полноразмерных прогонах по 68 ARW выбраны PNG 16 бит, баланс белого камеры,
без автоматического осветления и без изменения размера. В каждом прогоне
успешны все 68 файлов, без ошибок, пропусков и ожиданий свободной памяти.

Средний CPU = cpu_seconds / elapsed_seconds / effective_cpus × 100.
Сумма RSS может повторно учитывать общие страницы; пики измерены с интервалом
около секунды и не являются непрерывным системным мониторингом.
При одинаковом количестве активных задач роста памяти по мере очереди не видно.
«Максимальная скорость» в обоих случаях выбрала 1 → 2 → 4 → 8 → 4; устойчивую
выгоду уровней параллелизма надо проверить отдельно с учётом переходных задач.

Дополнительный прогон: 4 фотографии, «Авто», PNG 8 бит, половинный размер,
автоматическое осветление. Все 4 успешны за 3.641 с, пик суммы RSS 0.334 ГиБ,
ошибок и ожиданий памяти нет. Это проверка быстрого пресета; отдельного отчёта
для полноразмерного PNG 8 бит нет. Отмена подтверждена наблюдением пользователя;
приложенный JSON описывает завершённый прогон, а не прерванную очередь.

Известная неточность диагностики 0.1.0: width/height в секции files относятся
к метаданным исходника до уменьшения и ориентации, а не к размерам готового PNG.
В будущей версии отчёта следует различать входные и выходные размеры.

В исходники после этой проверки добавлен выбор русского / английского языка
и нейтральные подписи ARW. Эти изменения требуют следующей Windows-сборки;
исторический ZIP 0.1.0 в ветке windows-test-0.1.0 сохранён без изменений.
