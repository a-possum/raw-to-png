# Тестовая сборка для Windows 10/11 x64

Скачайте `ARW-to-PNG-Windows-test.zip`, распакуйте архив целиком и запустите `ARW-to-PNG.exe`. Python устанавливать не нужно. Папка `_internal` должна оставаться рядом с EXE.

Для первого прогона выберите «Авто» и PNG 16 бит, добавьте 68 ARW и укажите отдельную папку результата. После завершения нажмите «Сохранить отчёт» и отправьте JSON для анализа. Диагностика включена. Фотографии в отчёт не включаются.

Это неподписанная тестовая сборка, проверенная на настоящем Sony ARW через Wine. Проверка на настоящем Windows — следующий этап.

`ARW-to-PNG-source.zip` содержит резервную копию исходников на момент сборки. Исходники также доступны в этой ветке. Контрольные суммы архивов — в `SHA256SUMS.txt`.
