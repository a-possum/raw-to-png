# ARW → PNG 0.2.0 · Windows 10/11 x64

Готовое приложение: **ARW-to-PNG-Windows-x64-test-0.2.0.zip**, около 56 МБ.
Откройте файл на GitHub и нажмите **Download raw file**, затем распакуйте ZIP целиком
в новую папку и запустите **ARW-to-PNG.exe** двойным щелчком. Папку `_internal`
оставьте рядом с EXE. Python, PowerShell и установка приложения не требуются.

В этой версии: нейтральные подписи ARW, выбор Русский / English с сохранением языка,
исправленные размеры PNG в отчёте и улучшенная калибровка максимальной скорости.

Сначала проверьте несколько фотографий и оба языка. Затем запустите те же 68 ARW
в PNG 16 бит в режиме **«Максимальная скорость»**, в новую пустую папку результата.
Не используйте другие тяжёлые приложения во время этого прогона. После завершения
нажмите **«Сохранить отчёт»** и отправьте JSON для анализа. Диагностика включена.
В отчёте должны быть `app_version: 0.2.0` и `schema_version: 2`.

72 теста пройдены на Linux и 72 на Windows Python/Wine. Готовый EXE проверен
на настоящем ARW в трёх вариантах: PNG16, полноразмерный PNG8 и уменьшенный PNG8,
с русским / английским интерфейсом и кириллицей в путях. Первый пользовательский
прогон 0.2.0 на настоящем Windows — следующий этап. Сборка без цифровой подписи.

`ARW-to-PNG-source-0.2.0.zip` — резервная копия исходников. Контрольные суммы
архивов находятся в `SHA256SUMS.txt`, данные сборки — в `BUILD-INFO.json` внутри ZIP.
