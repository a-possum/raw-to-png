# ARW → PNG 0.4.0 · Windows 10/11 x64

Готовое приложение: **ARW-to-PNG-Windows-x64-test-0.4.0.zip**, около 56 МБ.
Откройте файл на GitHub и нажмите **Download raw file**. Закройте прежнюю версию,
распакуйте ZIP целиком в новую папку и запустите **ARW-to-PNG.exe**. Папка `_internal`
должна оставаться рядом с EXE. Python и установка приложения не нужны.

Новое в 0.4.0:

- Иконка фотокадра с синей стрелкой для EXE, окна и панели задач.
- Приблизительное оставшееся время после первых двух успешных фотографий.
  Оценка уточняется по ходу очереди; при ожидании памяти приостанавливается.
- Двойной щелчок по готовой строке открывает её PNG стандартным просмотрщиком.
  Для перемещённого или удалённого файла появляется понятное сообщение.

PNG 8 бит, ручное осветление, тёмная / светлая темы и Русский / English сохранены.
Для проверки добавьте несколько фотографий, дождитесь оценки и откройте готовый
PNG двойным щелчком. После отмены и завершения старая оценка должна исчезнуть.
После прогона можно сохранить JSON-отчёт. Диагностика включена; версия — 0.4.0.

98 тестов прошли на Linux и 98 на Windows Python/Wine. Готовый EXE проверен
на настоящем ARW в обоих языках и темах, с загрузкой иконки и проверкой пути
открываемого результата. В Windows PE присутствуют все семь размеров иконки.
Проверка стандартного просмотрщика и панели задач на вашем Windows — следующий
этап. Сборка без цифровой подписи.

Исходники — `ARW-to-PNG-source-0.4.0.zip`, контрольные суммы — `SHA256SUMS.txt`.
