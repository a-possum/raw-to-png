# ARW → PNG 0.3.0 · Windows 10/11 x64

Готовое приложение: **ARW-to-PNG-Windows-x64-test-0.3.0.zip**, около 56 МБ.
Откройте ZIP на GitHub и нажмите **Download raw file**. Закройте прежнюю версию,
распакуйте весь ZIP в новую папку и запустите **ARW-to-PNG.exe**. Папка `_internal`
должна оставаться рядом с EXE. Python и установка приложения не нужны.

В этой версии:

- По умолчанию полный PNG 8 бит; PNG 16 бит доступен для дальнейшей обработки.
- Автоосветление включается только вручную и видно в основном окне. Смена
  пресета или глубины цвета не меняет ваш выбор осветления.
- По умолчанию тёмная тема; светлая и Русский / English выбираются вверху окна.
- Сохраняются тема, язык и выбранные настройки. Старые готовые пресеты
  переводятся на новые значения однократно; свои настройки сохраняются.

Для проверки яркости преобразуйте один снимок в полный PNG8 и PNG16, меняя
только глубину цвета, оставив осветление выключенным, WB камеры и яркость 0 EV.
Для сравнения скорости используйте прежние 68 ARW, PNG16 и максимальный режим,
выбрав новую пустую папку. После прогона нажмите **«Сохранить отчёт»** и отправьте
JSON для анализа. Диагностика включена; версия отчёта — 0.3.0, схема — 2.

Проверено: 81 тест на Linux; 81 уникальная проверка Windows Python/Wine. Готовый
EXE проверен на настоящем ARW: русский / тёмная тема / PNG8, английский / светлая
тема / PNG16, английский / тёмная тема / половинный PNG8. Первый запуск подтвердил
8 бит, выключенное осветление и тёмную тему. Проверка 0.3.0 на вашем Windows —
следующий этап. Сборка без цифровой подписи.

Исходники: `ARW-to-PNG-source-0.3.0.zip`. Контрольные суммы — `SHA256SUMS.txt`.
